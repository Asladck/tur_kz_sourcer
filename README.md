# Қазақ–түрік топонимдік параллельдері / Kazak–Türk Toponimik Paralellikleri / Казахско-турецкие топонимические параллели

Интерактивное приложение к исследованию о родстве казахских и турецких топонимов.
Статический сайт на React + Vite, без бэкенда. Единственный источник данных — `toponyms_kz_tr.json`.

## Запуск

```bash
npm install
npm run dev            # разработка: http://localhost:5173
npm run build          # проверка типов → проверка шрифтов → сборка → пререндер страниц
npm run preview        # просмотр собранного сайта: http://localhost:4173
npm run check:glyphs   # только проверка шрифтов (см. ниже)
```

На защите без интернета: соберите сайт заранее и запустите `npm run preview`. Шрифты лежат
локально. Карта без интернета показывает упрощённую схему из Natural Earth вместо тайлов
OpenFreeMap. Открыть `dist/index.html` двойным щелчком не получится: страницам нужен
веб-сервер.

## Языки и адреса

Интерфейс на трёх языках, язык виден в адресе: `/kk/…`, `/tr/…`, `/ru/…`
(например, `/ru/entry/7`, `/tr/dictionary?type=cognate&comp=ak`). Переключатель
ҚАЗ · TÜR · РУС сохраняет текущую страницу и фильтры. Выбор запоминается: адрес `/`
открывает последний выбранный язык. Старые адреса без языка (`/entry/7`, `/stats`)
перенаправляются автоматически.

Все тексты интерфейса лежат в `src/i18n/kk.json`, `tr.json`, `ru.json`; их можно отдать на
вычитку. В русском файле предусмотрены формы множественного числа
(`{"one": "{n} пара", "few": "{n} пары", "many": "{n} пар"}`).

Содержимое словарных статей не переводится автоматически. Для русской версии в JSON есть
необязательные поля `kz.etymology_ru` и `tr.etymology_ru` (сейчас везде `null`). Если поле
заполнено, в русском интерфейсе показывается оно; если нет — казахский текст с пометкой
«Перевод готовится».

## Что заполнить перед публикацией

| Где | Ключ | Что |
|---|---|---|
| `src/i18n/*.json` | `home.authors`, `home.supervisor`, `home.institution` | автор(ы), научный руководитель, учреждение |
| те же файлы | `entry.citeAuthors` | автор в строке цитирования (ГОСТ для kk/ru, APA для tr) |
| те же файлы | `footer.rights` | строка в подвале |
| те же файлы | `history.items.*.text` | тексты таймлайна: `[ТЕКСТ АВТОРА]`, `[ТЕКСТ НА РУССКОМ]` |
| `src/i18n/ru.json` | `method.morphText`, `method.objNote`, `method.verifyLead`, `method.verify` | тексты методики на русском (`[ТЕКСТ НА РУССКОМ]`) |
| `src/i18n/*.json` | `method.bibPlaceholder`, `method.verify` | библиография; критерии проверки (черновик) |
| `site.config.json` | `siteUrl`, `basePath` | адрес сайта (canonical, Open Graph, цитирование) |
| `site.config.json` | `citationYear`, `featuredIds` | год в цитате; пары для главной и режима презентации |

## Данные

- **Координаты.** Впишите `lat`/`lon` в `toponyms_kz_tr.json` (десятичные градусы, WGS 84)
  или воспользуйтесь инструментом на карте (см. «Режим редактора»). Пары с обеими
  координатами появляются на карте с дугой; остальные остаются в списке
  «Координаттары анықталмаған (N)». Никакие координаты автоматически не подставляются.
- Пустые поля показываются как «Дерек жоқ / Veri yok / Нет данных», записи с
  `verified: false` получают значок «тексерілуде / inceleniyor / на проверке».
- **Морфемный разбор** (`src/data/morphology.ts`) — отдельный аналитический слой поверх
  JSON, требует проверки научным руководителем. От него зависят бирюзовая подсветка
  совпадающих компонентов, фильтр «Ортақ компонент», блок «Ұқсас жұптар», частотность
  компонентов и счётчики на странице звуковых соответствий. Формат описан в начале файла.
- **Звуковые соответствия** (`src/data/correspondences.ts`): `examples` — авторские
  примеры, `suggested` — мои предложения из корпуса; последние видны только в режиме
  редактора.

## Режимы

- **Режим редактора:** `?editor=1` к любому адресу (выключается через `?editor=0`).
  Появляются жёлтые плашки с `review_notes`, `link_type_draft`, `name_in_source`.
  На карте появляется инструмент ввода координат: выберите запись в списке, отметьте
  сторону KZ/TR и щёлкните по карте. Введённые координаты хранятся в этом браузере.
  Кнопка «JSON экспорттау» скачивает `toponyms_kz_tr.json`, в котором изменены только
  `lat`/`lon`. Замените им исходный файл и пересоберите сайт.
  Режим лишь скрывает элементы интерфейса: данные, включая `review_notes`, всё равно
  входят в публичную сборку.
- **Режим презентации:** значок экрана в шапке или адрес `/kk/present`.
  ← → (а также PageUp/PageDown, то есть кнопки пульта), F — полный экран, Esc — выход.
  Свой набор пар задаётся адресом `/kk/present?ids=7,79,70`.
- **Поиск:** Ctrl/Cmd+K или «/» с любой страницы. Ищет по казахскому и турецкому
  названию (без диакритики и в любой раскладке), по номеру и по компоненту (ақ, göl…).

## Цвет и шрифты

- Казахские данные всегда выделены золотым (`--steppe-gold`), турецкие — красным
  (`--anatolia-red`), общие совпадения (морфемы, дуги, активные элементы) — бирюзовым
  (`--turquoise`). Палитра задана в начале `src/styles/global.css`. Для текста используются
  более тёмные оттенки, чтобы контраст был не ниже WCAG AA.
- Шрифты: Noto Sans (текст), Noto Serif (заголовки и названия), Noto Sans Armenian
  (одно армянское слово в записи №31), Noto Sans Mono (имена полей). Все поставляются
  вместе с сайтом.
- `npm run check:glyphs` проверяет каждый символ интерфейса и данных по реальной таблице
  глифов (cmap) шрифтовых файлов, а не по объявленному unicode-range. Стрелки ← → ↔
  отсутствуют во всех подмножествах Noto, поэтому в тексте они рисуются встроенным SVG.
  Два артефакта данных — маркер списка из шрифта Word (U+F0B7) и стрелка ➔ — заменяются
  только при показе, сам файл данных не меняется. Проверка встроена в `npm run build`.

## Публикация

`npm run build` создаёт в `dist/` отдельный HTML-файл для каждой страницы на каждом языке
(408 страниц) с собственными `<html lang>`, `<title>`, description, canonical, hreflang и
Open Graph, а также `404.html`, `sitemap.xml` и `robots.txt`. Папку `dist/` можно выложить на
любой статический хостинг. Если сайт будет в подпапке (например, GitHub Pages
`https://user.github.io/toponyms/`), укажите `"basePath": "/toponyms/"`.

## Прочее

- **Карта:** MapLibre GL JS + тайлы OpenFreeMap (стиль Positron, без ключа). Подписи на
  карте выводятся на языке интерфейса, если они есть в OpenStreetMap. Офлайн-схема лежит в
  `src/data/basemap.json`; пересобрать её можно командой `node scripts/make-basemap.mjs`.
- **Картинка для соцсетей** `public/og-image.png` собирается из `scripts/og-image.html`
  (команда — в комментарии внутри файла).
- **Печать:** кнопка «Басып шығару» в карточке пары; вёрстка A4 описана в `src/styles/print.css`.
